📝 Tajuk dan Penerangan Projek <br />
   &emsp;• Nama Projek: Laman Web Nota Sihat. <br />
   &emsp;• Penerangan Ringkas: Nota Sihat ialah sebuah platform web interaktif yang menyediakan <br />
   &emsp;&emsp;nota ringkas dan mudah difahami oleh semua lapisan masyarakat. Laman web ini memberi <br />
     &emsp;&emsp;fokus kepada panduan praktikal mengenai cara-cara pencegahan pelbagai jenis penyakit <br />
     &emsp;&emsp;berjangkit dan tidak berjangkit. Matlamat utama adalah untuk meningkatkan kesedaran <br />
     &emsp;&emsp;kesihatan awam, memupuk gaya hidup sihat, serta memastikan maklumat pencegahan yang betul <br />
     &emsp;&emsp;dapat diakses oleh setiap individu demi kesejahteraan bersama. <br />

✨ Ciri-ciri Utama (Features) <br />
  &emsp;• Koleksi Nota Kesihatan Tersusun: Menyediakan nota ringkas mengenai cara – cara <br />
  &emsp; &emsp;pencegahan pelbagai penyakit berjangkit dan tidak berjangkit yang sesuai untuk semua lapisan masyarakat. <br />
  &emsp;• Reka Bentuk Responsif (Responsive Design): Antara muka yang dioptimumkan sepenuhnya untuk pelbagai <br />
  &emsp; &emsp;saiz skrin, sama ada telefon pintar, tablet, atau komputer. <br />

🛠️ Teknologi yang Digunakan (Tech Stack) <br />
  &emsp;Projek ini dibangunkan menggunakan teknologi web moden yang ringan dan pantas: <br />
  &emsp;• Frontend: <br />
     &emsp; &emsp;o HTML5 (Struktur halaman) <br />
     &emsp; &emsp;o CSS3 / Tailwind CSS/ Bootstrap Library (Gaya dan reka bentuk visual) <br />
     &emsp; &emsp;o JavaScript (Interaksi halaman) <br />
  &emsp;• Kawalan Versi (Version Control): <br />
     &emsp; &emsp;o Git & GitHub (Penyimpanan kod sumber dan pengurusan projek) <br />
  &emsp;• Penyaluran & Pengehosan (Hosting & Deployment): <br />
     &emsp; &emsp;o Vercel (Pautan automatik dari GitHub untuk live preview dan produksi) <br />
